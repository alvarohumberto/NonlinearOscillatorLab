Please consider our submission entitled "NonlinearOscillatorLab: A Python and Wolfram Language Toolkit for Energy-Based Classification, Accurate Period Computation and Closed-Form Solution of Duffing and Cubic--Quintic Oscillators" as an Original Software Publication in SoftwareX.

The manuscript accompanies two cross-validated MIT-licensed implementations, a Python package and a Wolfram Language (Mathematica) package, with automated test suites (15 Python tests; 31 Wolfram Language tests, all passing on Mathematica 15.0). The software provides equilibrium detection, energy-based turning points, a singularity-free period quadrature that reaches machine precision near separatrices, arbitrary-precision periods, closed-form Jacobi-elliptic solutions of the cubic-quintic equation, and numerical simulations. Every figure and table in the manuscript is regenerated by the bundled Mathematica scripts.

The accompanying code, tests, documentation and illustrative benchmarks are packaged separately. Before final submission, we will provide the public software repository and its archived persistent release identifier in the metadata table.
